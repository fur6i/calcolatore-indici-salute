# calcolatore-indici-salute 🧮

Un'applicazione CLI in Python per calcolare e analizzare i principali indici di salute e forma fisica a partire da dati antropometrici di base.

## 📌 Funzionalità

* **BMI (Indice di Massa Corporea):** Valutazione del rapporto peso/statura con relative fasce di riferimento (OMS).
* **Peso Forma Ideale:** Stima basata sulla formula di Lorenz differenziata per sesso.
* **BMR (Metabolismo Basale):** Calcolo del dispendio calorico a riposo tramite equazione di Mifflin-St Jeor.
* **Stima Grasso Corporeo (%BF):** Calcolo della percentuale adiposa tramite formula di Deurenberg con range specifici per uomo e donna.
